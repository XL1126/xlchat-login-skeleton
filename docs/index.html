XL Chat — 登录注册系统

现代化用户认证系统，前后端分离架构。目前已完成登录、注册、密码重置等核心功能， 可作为完整聊天系统的前端入口。聊天主功能尚未实现。

打开登录 UI 演示 克隆仓库
状态说明： 当前版本为半成品，仅包含登录注册功能；数据库使用 SQLite，适合单机小型应用， 不支持高并发与分布式部署。

在线 UI 演示

本页提供静态可交互登录界面：切换登录 / 注册 / 忘记密码， 表单校验与倒计时均可体验。无后端，不会真正提交数据。

项目简介

AUTH

认证入口

邮箱验证码注册、密码 / 验证码登录、忘记密码与安全链接重置。

JWT

无状态会话

JWT Token 认证，密钥可通过环境变量配置，部署时可自动生成。

MAIL

邮件通道

Nodemailer + SMTP，用于验证码与密码重置链接发送。

UI

深色界面

React 18 前端，约 270ms 进出场动画，深色主题与防自动填充处理。

现有功能

用户注册 · 邮箱验证码 密码登录 验证码登录 忘记密码 密码重置 JWT 认证 邮件发送 SQLite 持久化 丝滑动画 深色主题

技术栈

前端

React 18 · React Router 6 · Vite · CSS3

后端

Express.js · SQLite3 · JWT · bcrypt · Nodemailer

主要 API

方法路径说明
POST/api/sign_up用户注册
POST/api/sign_in用户登录
POST/api/send_verification_code发送验证码
POST/api/forgot_password忘记密码
POST/api/reset_password重置密码
POST/api/logout用户登出
