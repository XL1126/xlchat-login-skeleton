XL Chat — 登录注册系统

现代化用户认证系统，前后端分离。已实现注册、登录、密码重置等核心功能， 可作为完整聊天系统的前端入口。 当前版本为半成品：仅认证，不含聊天主功能。 数据库使用 SQLite，适合单机小型应用，不支持高并发与分布式部署。

打开登录 UI 演示 克隆仓库
演示如何对照真实代码： 本仓库 Pages 上的 demo/ 是对照 client/src（App / AuthContext / SignIn / SignUp / ForgotPassword / ResetPassword / Home / Logo / PasswordInput / Toast / Animated / App.css / index.css） 与 server/index.js（校验与错误文案）从 0 移植的静态实现。 样式与 DOM 类名、占位符、按钮文案、路由路径与页面标题一致；无 Node 时 API 落在浏览器 localStorage， 错误信息与真实后端对齐（如「用户不存在」「密码错误」「验证码无效或已过期」「请稍等5分钟后再试」）。 本地部署前后端后，访问同一套界面。

现有功能

POST /api/sign_up

用户注册

用户名 + 邮箱 + 验证码 + 密码确认；服务端校验密码一致、长度 ≥6、验证码有效、邮箱未注册。

POST /api/sign_in

登录

login_type 为 password / code；成功返回 JWT 与 user（id / username / email）。

POST /api/send_verification_code

邮箱验证码

6 位数字，5 分钟有效；5 分钟内重复请求返回「请稍等5分钟后再试」。

POST /api/forgot_password

忘记密码

无论邮箱是否存在均提示「如果邮箱存在，重置链接已发送」；重置 token 15 分钟有效。

POST /api/reset_password

密码重置

链接格式 /reset_password?token=...；成功后前端 2 秒跳转登录页。

UI

纯黑背景、#6780FE 主色、XL 字标、胶囊输入框、密码眼睛、顶部 Toast、Animated 270ms 分段入场。
