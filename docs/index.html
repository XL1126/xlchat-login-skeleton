XL Chat — 登录注册系统

现代化用户认证系统，前后端分离。已实现注册、登录、密码重置等核心功能， 可作为完整聊天系统的前端入口。 当前版本为半成品：仅认证，不含聊天主功能。 数据库使用 SQLite，适合单机小型应用，不支持高并发与分布式部署。

打开登录 UI 演示 克隆仓库 项目站点
演示说明： demo/ 页面的界面结构、类名、文案与动画时长（270ms）均对照仓库 client/src 下真实组件实现（SignIn / SignUp / ForgotPassword / ResetPassword / Home / Logo / PasswordInput / Toast / Animated / App.css）， 路由也与 App.jsx 一致：/sign_in、/sign_up、/forgot_password、/reset_password。 GitHub Pages 上没有 Node 后端，提交会被前端逻辑模拟；本地部署后访问真实前后端时，看到的就是同一套 UI。

现有功能

POST /api/sign_up

用户注册

用户名 + 邮箱 + 验证码 + 密码确认；前端校验两次密码一致性。

POST /api/sign_in

登录

密码登录 / 验证码登录两种模式；登录成功写入 JWT 与用户信息。

POST /api/send_verification_code

邮箱验证码

Nodemailer SMTP 发送；前端 60 秒倒计时，按钮文案「发送验证码 / N秒 / 发送中...」。

POST /api/forgot_password

忘记密码

标题「重置统一登录密码」；成功提示「如果邮箱存在，重置链接已发送」。

POST /api/reset_password

密码重置

邮件链接携带 token；设置新密码后 2 秒跳转登录页。

UI

深色认证界面

纯黑背景、胶囊输入框、#6780FE 主色、XL 字标、顶部 Toast 错误提示、防浏览器自动填充。

技术栈

前端 client/

React 18 · React Router 6 · Vite · React Context（Auth）· CSS3 · 分段进出场动画

后端 server/

Express.js · SQLite3 · JWT · bcrypt · Nodemailer · 可热读 .env
