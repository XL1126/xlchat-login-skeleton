XL Chat — 登录注册系统

前后端分离的用户认证系统：注册、登录、密码重置。当前为半成品（仅认证，聊天主功能未实现）。 数据库 SQLite，适合单机小型应用。

打开登录 UI 演示 查看源码
演示与源码的对应关系： demo/ 按 client/src 模块拆分（Animated / Logo / PasswordInput / Toast / AuthContext / pages/* / App / main）， 样式与 App.css、index.css 一致；API 错误文案对照 server/index.js。 入场动画 1:1：mount 后 opacity:0 → delay 后写入 animation: name 270ms ease-out forwards + animation-delay: delay（双延迟）， keyframes 动态注入；同路由 re-render 不重播。

功能一览

/api/sign_up

注册

用户名 + 邮箱 + 验证码 + 密码确认；密码 ≥6 位、邮箱唯一、验证码有效。

/api/sign_in

登录

密码登录 / 验证码登录；返回 JWT 与 user（id / username / email）。

/api/send_verification_code

验证码

6 位、5 分钟有效；5 分钟内重复请求 →「请稍等5分钟后再试」。

/api/forgot_password

忘记密码

提示「如果邮箱存在，重置链接已发送」；token 15 分钟有效。

/api/reset_password

重置密码

?token=... 校验后设置新密码，2 秒后回登录页。

UI

深色认证界面

纯黑底、#6780FE、XL 字标、胶囊输入、Toast、Animated 六选一入场。
